# 🎓 大邱大学搜索系统 | Daegu University Search

韩国大邱大学 (Daegu University) 专业搜索、学费查询、申请条件一站式平台。

## ✨ 功能

- 🔍 **专业搜索** — 按关键词搜索专业名称、学费、语言要求等
- 🎚️ **分类筛选** — 本科 / 硕士 / 博士 / 专升本
- 💰 **学费查询** — 韩元 + 人民币双币种显示
- 📋 **申请指南** — 学历要求、语言标准、签证材料
- 🏆 **奖学金信息** — 入学奖学金、成绩奖学金、GKS 奖学金
- 🏠 **留学生活** — 住宿、交通、打工、生活成本

## 🚀 使用

直接打开 `index.html` 即可使用，或访问 [GitHub Pages 演示](https://mengchuijie.github.io/daegu-university-search/)。

## 📊 数据来源

- [大邱大学官网](https://www.daegu.ac.kr)
- [大邱大学中文官网](http://daegu.jupinzan.com/)
- 2026 年招生简章及韩国法务部留学签证政策

## 🛠️ 技术栈

- 纯前端单页应用 (HTML + CSS + Vanilla JS)
- 无后端依赖，数据内置 JSON
- 响应式设计，支持移动端
- 可部署到 GitHub Pages / Vercel / Netlify
